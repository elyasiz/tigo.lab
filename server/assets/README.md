The TIGO logo is a PNG encoding of the existing catalog logo in dist/assets/.

PDF fonts are static Fredoka 600 and Nunito 400/700, downloaded from the official
Google Fonts CSS API. Their SIL Open Font License texts are included in
../../dist/assets/fonts/Fredoka-OFL.txt and Nunito-OFL.txt.

Sources: https://fonts.google.com/specimen/Fredoka and https://fonts.google.com/specimen/Nunito.
